Projects

Earlier work, 2022–2024.

  1. 2023–2024

    Deep learning for hyperspectral image denoising

    Xi'an Jiaotong University

    A series on hyperspectral image (HSI) denoising: HSIDMamba, among the first bidirectional state-space models for HSI denoising with linear-complexity spatial-spectral modeling (first author, arXiv 2024); a spectral aggregation cross-square transformer (first author, ICPR 2024); and co-authored region-aware sequence-to-sequence learning (ECCV 2024) and Fourier–spatial-spectral bridging (ACM MM 2024).

    • HSIDMamba code
    • RAS2S code
  2. 2022

    Binocular trajectory prediction

    A binocular-camera pipeline that detects a flying target, estimates its 3-D position with EPnP, tracks it with a Kalman filter, and predicts the landing point by least-squares fitting.

    • Code
  3. 2022

    imgAug

    Dataset augmentation tool

    A desktop tool that augments object-detection datasets (flip, rotate, affine, translate, scale, contrast/brightness, noise, color, random occlusion) while updating the bounding-box annotations accordingly.
